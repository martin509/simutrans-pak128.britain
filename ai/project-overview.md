# Project overview

**Covers**: what Pak128.Britain-Ex is, where it came from, and how it relates to Standard
pak128.Britain and Simutrans-Extended.

## Initial facts

- Pak128.Britain is a 128-pixel-tile graphics and data set (pakset) for Simutrans depicting
  Britain. The Extended edition (Pak128.Britain-Ex) is the edition used with Simutrans-Extended.
  `[CODE New master @ e36ec2321]`
- The pakset's own `New/readme.txt` describes an early "1.0 (beta)" release dated 7th July 2009
  and the history of pre-release and release versions that followed. This is the historic release
  narrative, not a description of the current state. `[CODE New master @ e36ec2321]`
- The pakset is licensed under the Artistic License (`New/licence.txt`). `[CODE New master @ e36ec2321]`
